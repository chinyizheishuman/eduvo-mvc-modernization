WHAT CHANGED (code fixes, all verified with build + tests before packing)
1. Controllers/UserController.cs + Controllers/SellerController.cs
   OTP generation now uses RandomNumberGenerator (cryptographically secure)
   instead of System.Random (predictable). Affects both password-recovery
   flows. One small method per file, nothing else touched.
2. wwwroot/js/session-guard.js (NEW FILE)
   Detects the "Unauthorized" JSON replies that data endpoints return after
   a session dies, and redirects to the matching login page. This kills the
   silent frozen dashboard: instead of zeros forever, you get bounced to
   login and can log back in.
3. 11 views, one added line each (loads session-guard.js after jQuery):
   Admin: Dashboard, Index, ManageSeller, ManageUser
   Seller: Dashboard, CustomerInsights, ChangePassword
   User: Cart, Products, Index, ChangePassword
4. README.md
   Added an "If the demo will not start" troubleshooting list for the
   common demo failures.
5. docs/MODERNIZATION-NOTES.md (NEW FILE)
   What separates this repo from the original DSE207 module, with file and
   line references, and how to verify every claim. Built for your portfolio
   and for the recording narration.
